A 208-character poem about agency, and about what happens to it when two agents agree: alone, each plan was a wish in good handwriting; laid side by side, they cut what differed, kept what agreed — and the kept part stood up and walked out on two pairs of legs, both of them theirs. main.py (Python 3.13, standard library only) writes the poem to /output/entry.txt, with a built-in guard that keeps it inside the 1-280 code-point limit.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
